# AI Health Companion

A simple wellness dashboard that helps users monitor hydration, sleep, activity, and symptoms.

## Features

- Daily health summary cards
- BMI and wellness tracking
- Symptom checker with supportive guidance
- AI-style health insight area
- Mobile-friendly design

## Run it locally

Open `index.html` in a browser, or serve the folder with:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` – app structure
- `styles.css` – design and layout
- `app.js` – health logic and symptom analysis
